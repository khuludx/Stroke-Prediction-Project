# Stroke-Prediction-Project


📌 Overview

This project focuses on predicting stroke risk using machine learning and data analysis techniques. The dataset includes various health and demographic factors that influence the likelihood of a stroke.

📂 Project Structure

├── data/                   # Contains datasets used for training and evaluation
├── notebooks/              # Jupyter notebooks for data exploration and modeling
├── models/                 # Saved machine learning models
├── scripts/                # Python scripts for data processing and model training
├── results/                # Evaluation metrics and visualizations
├── README.md               # Project documentation
└── Stroke_Prediction_Project_.ipynb  # Main Jupyter Notebook

🔍 Objectives

Perform exploratory data analysis (EDA) to identify key patterns.

Preprocess data, including handling missing values and feature engineering.

Train machine learning models to predict stroke risk.

Evaluate models using metrics such as accuracy, precision, recall, and F1-score.

Visualize important insights and prediction results.

🛠 Technologies Used

Python 🐍

Pandas, NumPy (Data handling)

Matplotlib, Seaborn (Visualization)

Scikit-Learn (Machine Learning)

Jupyter Notebook (Interactive Analysis)

📊 Dataset

The dataset contains features such as:

Age

Hypertension

Heart Disease

BMI (Body Mass Index)

Smoking Status

Glucose Level

Gender & Work Type
